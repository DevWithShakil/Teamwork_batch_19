# Print Numbers from 1 to 300 Using Python Loop

A simple Python project that prints numbers from **1 to 300** using a `for` loop.

---

## 📌 Project Description

This project demonstrates how to use a **for loop** in Python to print numbers sequentially from **1 to 300**.

It is a beginner-friendly project for learning:

- Python syntax
- `for` loop
- `range()` function
- Console output

---

## 🚀 Features

- Prints numbers from **1 to 300**
- Uses Python `for` loop
- Beginner-friendly example
- Easy to understand and modify

## 💻 Code

```python
# Print numbers from 1 to 300

for i in range(1, 301):
    print(i)
```
